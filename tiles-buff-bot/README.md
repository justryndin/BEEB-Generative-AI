# ❄️ Бот бафов союза — Tiles Survive, сезон «Эра метели»

Telegram-бот распределяет сезонные бафы (−15% к стройке и −15% к исследованиям) между игроками союза, чтобы ни один баф не пропал зря и помощь доставалась всем по очереди.

## Как это работает для игрока

Вручную игрок вводит только **ник** (один раз) и **время по таймеру**. Всё остальное — кнопками.

Меню внизу экрана:
```
[🏗 Моя стройка]          [🔬 Моё исследование]
[🎁 Отдать баф: стройка]  [🎁 Отдать баф: исследование]
[📋 Очередь]              [👤 Профиль]
[❓ Как это работает]     [⚙️ Управление]   ← только у админов
```

**Встать в очередь:** «🏗 Моя стройка» → *Шаг 1*: нажать здание → *Шаг 2*: нажать уровень → *Шаг 3*: написать время с таймера (`21д 5ч` или просто `21`). Для исследования шагов два: ветка и время. На каждом шаге есть «◀️ Назад» и «❌ Отмена».

**Отдать баф:** «🎁 Отдать баф: стройка» → бот пишет, кому отдать → отдаёшь в игре → «✅ Отдал». Если игрока не найти — «🔁 Другой игрок». Бронь держится 30 минут.

**Если что-то поменялось:** «🏗 Моя стройка» → «🔧 Поправить остаток времени» / «✏️ Началась новая стройка» / «🏁 Готово» (с подтверждением).

**Профиль:** «✏️ Сменить ник», «🚪 Удалить меня из бота».

Получатель бафа получает уведомление. Через 48 часов бот напоминает тому, кто отдал, что его баф снова готов.

## Управление (владелец и админы R4)

Кнопка «⚙️ Управление» (или `/admin`):
- **👥 Игроки** — список со страницами. Нажатие на игрока открывает его карточку:
  - 🔥 срочно вкл/выкл, 🏁 убрать из очереди, ✏️ записать стройку/исследование за него;
  - 🎁 «Его баф → кому?» — подобрать получателя, если игрок отдаёт баф без бота;
  - ⭐ сделать админом / снять (только владелец);
  - 🗑 **удалить из бота** (с подтверждением) — если человек ушёл или перешёл в другой союз. История бафов сохранится, игрок получит сообщение.
- **➕ Добавить игрока без Telegram** — написать ник, дальше всё кнопками.
- **⚙️ Правила очереди** — цикл 1:1 / 2:1 / 3:1, бафов подряд одному, сводка в группу вкл/выкл.
- **📣 Сводка в группу сейчас**.

**Вышел из группы → предложение удалить.** Если игрок выходит из Telegram-группы союза (или его исключают), владелец и админы получают сообщение «🚪 Ник вышел из группы союза. Удалить?» с кнопками [🗑 Удалить] [Оставить]. Чтобы это работало, **бот должен быть администратором группы**.

Текстовые команды (`/add`, `/gave`, `/set`… список — `/commands`) остались как запасной вариант.

## Справочник построек и исследований

Когда игрок записывает таймер, бот спрашивает, что именно идёт:
- **стройка:** здание из списка → уровень → остаток времени. Бот сразу показывает справочное время и требования для этого уровня;
- **исследование:** ветка (Развитие, Экономика, Дуэль альянсов, Спецназ…) → название и уровень (можно пропустить) → остаток.

В очереди видно, кто что строит: «Мура — 20д · Электростанция → 24».

Если введённое время в полтора раза больше справочного, бот переспросит: возможна опечатка.

Команда `/catalog` показывает справочник: время улучшения Электростанции и Казарм по уровням, список веток исследований и статистику союза.

**Откуда данные.** Время по уровням взято с [tilessurvive.net](https://tilessurvive.net/en/buildings/) (октябрь 2026) и указано без бонусов к скорости:
- Электростанция 1–30;
- Казармы 1–30 (на сайте есть явные несостыковки, поэтому помечены как ≈).

По Лаборатории, остальным зданиям и отдельным исследованиям публичных таблиц сейчас нет: на сайте сказано, что данные потеряны и восстанавливаются. Поэтому бот копит **свою статистику союза**: медиана заявленных игроками времён по каждому зданию и уровню видна в `/catalog`. Справочник лежит в `bot/gamedata.py`, туда легко дописать новые данные.

## Правила распределения

| Правило | По умолчанию |
|---|---|
| Один баф срезает | 15% от **заявленного** игроком времени (`mode=declared`) |
| Стройка: бафаем до остатка | 5–7 дней |
| Исследование: бафаем до остатка | 7–8 дней |
| Ротация | `BBW`: 2 бафа самым большим таймерам, 1 — тому, кто дольше всех ждёт |
| Подряд одному игроку | не больше 2 |
| 🔥 Срочно (ставит админ) | вне очереди, пока таймер не закроется |
| Баф у игрока восстанавливается | раз в 48 часов |

Баф назначается, только если остаток больше верхней границы цели и после бафа не опустится ниже нижней. Лишних бафов бот не даёт.

Баф в игре действует и на того, кто его отдал, поэтому бот срезает таймер и у донора.

Если игрок запустил несколько строек или исследований, он указывает самое долгое: баф ложится на все сразу.

Все числа меняются командой `/set` без перезапуска, список — `/settings`.

## Установка (≈15 минут)

### 1. Создать бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя (видно в чатах): например `Метель · Бафы союза`.
3. Username (латиницей, должен заканчиваться на `bot`): например `MetelBuffBot`.
4. BotFather пришлёт **токен** вида `123456789:AA...`. Это пароль от бота: никому его не показывай и не публикуй в чатах.
5. По желанию: `/setdescription`, `/setabouttext`, `/setuserpic`.

### 2. Узнать свой Telegram ID

Напиши [@userinfobot](https://t.me/userinfobot) — он пришлёт число `Id`.

### 3. Запустить на сервере (Ubuntu/Debian)

```bash
# Docker, если ещё не стоит
curl -fsSL https://get.docker.com | sh

# Код бота
git clone -b claude/dazzling-maxwell-uf3pkt https://github.com/justryndin/BEEB-Generative-AI.git
cd BEEB-Generative-AI/tiles-buff-bot

# Настройки
cp .env.example .env
nano .env          # впиши BOT_TOKEN и OWNER_IDS

# Запуск
docker compose up -d --build
docker compose logs -f   # проверить, что запустился (выход — Ctrl+C)
```

Напиши боту `/start`: он спросит ник, после этого появится меню.

### 4. Подключить группу союза (по желанию)

1. Добавь бота в группу союза и **сделай его администратором** (нужно, чтобы бот замечал, кто вышел из группы).
2. Напиши в группе `/chatid` и впиши число в `ALLIANCE_CHAT_ID` в `.env`.
3. `docker compose up -d` — после этого регистрироваться смогут только участники группы, а сводка будет приходить туда каждый день.

### Обновление, остановка, резервная копия

```bash
git pull && docker compose up -d --build   # обновить
docker compose down                        # остановить
cp data/bot.db ~/bot-backup-$(date +%F).db # резервная копия базы
```

### Безопасно ли рядом с VPN?

Да:
- бот работает в отдельном контейнере;
- он **не открывает ни одного порта**, а только сам подключается к серверам Telegram;
- память ограничена 256 МБ, процессор — половиной ядра;
- внутри контейнера бот работает без прав root;
- конфиги VPN бот не трогает.

## Для разработчика

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt pytest
pytest -q                       # тесты
BOT_TOKEN=... OWNER_IDS=... python -m bot.main   # запуск локально
```

Структура:
- `bot/logic.py` — расчёт бафов и ротации (чистые функции);
- `bot/service.py` — база и бизнес-логика;
- `bot/handlers_*.py` — Telegram;
- `bot/scheduler.py` — фоновые задачи: брони, напоминания, сводка.
