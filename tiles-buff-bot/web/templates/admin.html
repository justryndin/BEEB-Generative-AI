🛠 Настройки очереди

Без кода зарегистрироваться нельзя. Пусто — регистрация открыта всем.
«По доле»: следующий тот, кто получил меньшую часть своих положенных бафов, — все доходят до цели примерно одновременно. Цикл ниже работает только в режиме «круг + цикл».
Если остаток сам дойдёт до цели быстрее — игрок идёт первым, чтобы положенный баф не пропал. 0 — выключить.
Кто держит готовый баф дольше — пропускает ход, пока не отдаст. 0 — выключить.
Доля помощи приоритетной стройке растёт во столько раз медленнее — бафы ей идут чаще, но остальных не забываем.
Первыми — кто не построил Электростанцию до уровня из «Приоритет для уровней ниже».
Плюс все, кто стоит в очереди или отдавал бафы за этот срок.
После каждого полученного бафа и если игрок давно не сверялся (ускорения сайт не видит). 0 — не просить.
