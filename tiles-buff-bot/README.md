# ❄️ Бафы союза — сайт очереди сезонных бафов (Tiles Survive)

Сайт распределяет сезонные бафы (−15% к стройке и исследованиям) между игроками союза: подсказывает, **кому** отдать баф, ведёт очередь, считает статистику и даёт советы по игре. Работает с телефона и компьютера, без Telegram.

## Что на сайте

| Раздел | Что там |
|---|---|
| 🏠 **Главная** | Карточки «что тебе сделать сейчас» (сверь время, встань со следующим), закреплённое объявление и ближайшее событие. Живые блоки «🔬 Исследование» и «🏗 Стройка»: у каждого полоска «получил X из Y» и строка «почему здесь» |
| ➕ **Встать в очередь** | Здание → уровень → время. Встал один раз — стоишь, пока идёт стройка |
| 🎁 **Я отдал баф** | Нажимаешь на игрока, которому отдал (сверху — 👉 следующий) |
| 📣 **Союз** | Объявления R4 (закрепить, «важное» — всем на телефон, «Буду / Не смогу», «прочитали X из Y») и 📅 недельные события союза с напоминаниями |
| 👤 **Профиль** | 💎 Моя выгода, 🔔 уведомления на телефон, ник и PIN |
| ⚙️ **Управление** | Игроки с заметками и метками, 📈 аналитика, 📜 журнал с отменой, настройки очереди |

## Как движется очередь

- **По доле от положенного.** Каждому положено столько бафов, сколько нужно до цели (стройка — пока не останется ~3 дн., исследование 7–8 дн.). Следующий — у кого заполнена меньшая доля: «1 из 5» (20%) раньше, чем «2 из 4» (50%). Все доходят до цели примерно одновременно.
- **⏰ Горит** — если таймер сам дойдёт до цели меньше чем за 24 ч, игрок первый, иначе его баф пропадёт.
- **⚡ Приоритет** — Электростанция ниже 30 ур.: доля растёт вдвое медленнее, бафы ей идут чаще.
- **⏳ Взаимность** — держишь готовый баф дольше 24 ч — пропускаешь ход, пока не отдашь.
- **🎲 Рулетка** — если в очереди на стройку никого нет, баф не пропадает: сайт выбирает активного игрока союза (заходил за 3 дня, стоит в очереди или отдавал бафы). Первыми — кто не построил Электростанцию 30 (уровень игрок указывает в профиле, R4 — в карточке, или сайт узнаёт его из записи стройки), дальше — кто реже получал, при равенстве — жребий. Записавшиеся всегда раньше рулетки.
- **⏸ Пауза 12 ч** после бафа, 🔥 «срочно» от R4, баф восстанавливается за 48 ч.
- **Жизнь записи:** после каждого бафа сайт просит сверить время с игрой (ускорения он не видит); стройка закончилась — предлагает встать со следующим уровнем.

Все числа меняются в «Управлении → Настройки». Там же можно вернуть старый порядок «круг + цикл».

## 💡 Совет дня и база знаний

Новичку — один короткий гайд «🌱 Начни здесь» (5 минут). Всё остальное — база знаний: около 70 коротких советов (`core/tips.py`) и подробные гайды в «📣 Союз → 📚 Гайды». На главной каждый день — «Совет дня» под ситуацию игрока (держит баф, нет уведомлений, стройка в очереди, Электростанция ниже 30) и день недели; кнопка «🔄 Ещё совет» достаёт следующий. Совет дня приходит и уведомлением (днём, один раз). Новый совет — одна строка `Tip(...)` в `core/tips.py`.

## 🔔 Уведомления на телефон

Настраивать на сервере **ничего не нужно**: ключи создаются сами при первом запуске. Нужен только HTTPS (он есть).

Игрок: **Профиль → 🔔 Уведомления → «Включить на этом устройстве»** → разрешить.
- **Android** — Chrome, одна кнопка.
- **iPhone** (iOS 16.4+) — сначала Safari → «Поделиться» → «На экран Домой», открыть сайт с иконки, потом «Включить».

Что приходит: «баф готов — отдай X», «держишь баф больше суток», «тебе отдали баф — сверь время», «ты следующий», «стройка закончилась», важные объявления, напоминания о событиях. Ночью (00–08) тихо. Каждый вид можно выключить. Охват видно в «📈 Аналитике».

## 📈 Аналитика для R4

«Управление → Аналитика»: сколько бафов союза реально используется, сколько готовый баф лежит до отдачи, сколько ждут первого бафа, сколько ещё положено очереди и за сколько дней она рассосётся, кто держит бафы и кто перестал заходить — с готовым списком «что сделать».

## Два способа выйти в интернет

Выбирается строкой `COMPOSE_PROFILES` в `.env`:

- **`direct`** — сайт на **отдельном IP** сервера (`SITE_IP`) с доменом `SITE_DOMAIN`, HTTPS выпускается автоматически (Caddy + Let's Encrypt). В DNS у регистратора: A-записи `@` и `www` → `SITE_IP`. Порты 80/443 на этом IP должны быть свободны: если Xray/nginx слушают «все адреса» (`*:443`, `0.0.0.0:80`), их нужно привязать к IP VPN.
- **`tunnel`** — через Cloudflare Tunnel, порты не нужны (инструкция ниже).

## Установка через Cloudflare Tunnel (вариант `tunnel`)

Сайт **не открывает портов** и не трогает Xray/nginx: он сам подключается к Cloudflare, а Cloudflare показывает его по вашему адресу с HTTPS. IP сервера в DNS не светится.

### Шаг 1. Домен в Cloudflare (один раз)

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатно).
2. **Add a domain** → впишите свой домен → план **Free**.
3. Cloudflare покажет **два NS-сервера** (вида `xxx.ns.cloudflare.com`). В панели регистратора домена замените NS-серверы на эти два. Обновление занимает от 10 минут до нескольких часов — Cloudflare пришлёт письмо, когда домен станет **Active**.

### Шаг 2. Создать туннель

1. В Cloudflare откройте **Zero Trust** → **Networks** → **Tunnels** → **Create a tunnel**.
2. Тип — **Cloudflared**, имя — например `buff-site` → **Save**.
3. На экране установки выберите **Docker**. В команде будет длинная строка после `--token` — **скопируйте только её** (это `TUNNEL_TOKEN`). Никому её не пересылайте.
4. **Next** → вкладка **Public Hostname**:
   - **Subdomain**: `buff` (или что хотите)
   - **Domain**: ваш домен
   - **Service**: Type **HTTP**, URL **`web:8000`**
5. **Save tunnel**. DNS-запись Cloudflare создаст сам.

### Шаг 3. Обновить код на сервере и выключить бота

```bash
cd ~/BEEB-Generative-AI/tiles-buff-bot
docker compose down          # остановить Telegram-бота
git pull                     # скачать сайт
```

### Шаг 4. Настройки

```bash
cp .env .env.bot-backup 2>/dev/null; cp .env.example .env
nano .env
```
Впишите `TUNNEL_TOKEN=` — строку из шага 2 (без пробелов и кавычек). При желании поменяйте `SITE_NAME`. Сохранить: **Ctrl+O → Enter → Ctrl+X**.

### Шаг 5. Запуск

```bash
docker compose up -d --build --remove-orphans
docker compose ps                         # web и tunnel должны быть Up
curl -s http://127.0.0.1:8765/healthz     # должно ответить {"ok":true}
docker compose logs tunnel --tail 20      # строки «Registered tunnel connection» = туннель работает
```

Откройте `https://buff.ваш-домен` — должна открыться главная страница.

### Шаг 6. Стать владельцем

1. На сайте нажмите **«✨ Я новенький»** и зарегистрируйтесь со своим ником и PIN.
2. На сервере:
   ```bash
   docker compose exec web python -m web.manage owner "Ваш ник"
   ```
3. Обновите страницу — появится **⚙️ Управление**. Сразу задайте там **код союза** и сообщите его в игровом чате.
4. Админов R4 назначаете в «Управлении» → игрок → «⭐ Сделать админом».

**Данные из Telegram-бота сохраняются.** Игроки и очередь переезжают на сайт; при регистрации со старым ником игрок задаёт PIN и получает свои записи.

## Полезные команды

Из папки `~/BEEB-Generative-AI/tiles-buff-bot`:

| Что нужно | Команда |
|---|---|
| Работает ли | `docker compose ps` |
| Логи сайта | `docker compose logs web --tail 50` |
| Логи туннеля | `docker compose logs tunnel --tail 50` |
| Перезапустить | `docker compose restart` |
| Обновить сайт | `git pull && docker compose up -d --build` (после обновления с уведомлениями `--build` обязателен) |
| Резервная копия базы | `docker compose cp web:/app/data/bot.db ~/buff-backup-$(date +%F).db` |
| Список игроков | `docker compose exec web python -m web.manage players` |
| Сбросить PIN | `docker compose exec web python -m web.manage reset-pin "Ник"` |

| Проблема | Что делать |
|---|---|
| Сайт не открывается, `tunnel` перезапускается | Неверный `TUNNEL_TOKEN` в `.env` → исправьте и `docker compose up -d` |
| Cloudflare пишет «Bad gateway» | В Public Hostname должно быть `HTTP` и `web:8000` |
| Нет «⚙️ Управление» | Выполните команду `owner` из шага 6 и обновите страницу |

## Для разработчика

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt pytest httpx
pytest -q
DB_PATH=data/dev.db SECURE_COOKIES=0 uvicorn web.app:get_app --factory --reload --port 8765
```

- `core/` — логика очереди и ротации (`logic.py`), база и сервис (`db.py`, `service.py`), справочник построек (`gamedata.py`).
- `web/` — FastAPI-приложение (`app.py`), шаблоны Jinja2, стили и немного JS, SVG-графики (`charts.py`), служебные команды (`manage.py`).

Справочные времена — с [tilessurvive.net](https://tilessurvive.net/en/buildings/) (октябрь 2026), советы по исследованиям — по открытым гайдам (tilessurvive.net, mturbogamer.com, lootbar.gg).
